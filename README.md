# What's Training? Turtle WoW port

What's Training? is an addon for Turtle WoW that adds a list of available trainer spells to the spellbook.

![Screenshot](./images/screenshot.png)

Please feel free to create any issues.

## Installing

Download `WhatsTraining_Octo-vX.Y.Z-classic.zip` from the latest release on the
[Releases page](https://github.com/Vaterade/WhatsTraining_Octo/releases) and unzip it into
`Interface/AddOns/`, so there is a `WhatsTraining_Octo` folder with `WhatsTraining_Octo.toc` directly inside.
Changes in each version are in `CHANGELOG.md`.
